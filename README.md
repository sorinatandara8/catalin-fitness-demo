# Demo website — Cătălin Tătulescu

Landing page static, responsive, pregătit pentru publicare pe Vercel.

## Previzualizare locală

Din acest director:

```bash
python3 -m http.server 4173
```

Apoi deschide `http://localhost:4173`.

## Publicare

Proiectul poate fi urcat ca repository separat pe GitHub. În Vercel se importă repository-ul fără build command și cu directorul rădăcină implicit.
